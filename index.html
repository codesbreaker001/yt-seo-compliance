What this application does

It is a private, single-user automation tool for our own YouTube channel. It reads the metadata of our own videos with videos.list and updates the title, description and tags of our own videos with videos.update. It never uploads or deletes videos, never accesses any other channel, and never downloads, caches or redistributes YouTube audiovisual content.

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service and the Google Privacy Policy.
